Chapter 01 · Git

基础命令

初始化仓库、克隆远程、查看状态 —— 一切的开始

git init

在当前目录初始化一个新的 Git 仓库，创建 .git 隐藏文件夹

$ git init
Initialized empty Git repository in /project/.git/
git clone

从远程仓库下载完整副本，包括所有分支和历史记录

$ git clone https://github.com/user/repo.git
$ git clone git@github.com:user/repo.git # SSH 方式
git status

查看当前工作区状态：哪些文件被修改、已暂存或未跟踪

$ git status
On branch main
Changes not staged for commit:
modified: src/App.tsx
Untracked files:
new-file.ts
git log

查看提交历史，可加 --oneline 简化输出，--graph 显示分支图

$ git log --oneline --graph
* a1b2c3d feat: add login page
* e4f5g6h fix: button style
* i7j8k9l init: project setup
常用组合：git log --oneline --graph --all --decorate 查看完整分支图
