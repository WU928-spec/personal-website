Remote
git add

将工作区的修改添加到暂存区，准备提交

$ git add filename.ts
$ git add . # 全部
$ git add -p # 交互式
git commit

将暂存区的内容保存到本地仓库，形成一次提交记录

$ git commit -m "feat: add login"
$ git commit -am "fix: typo" # add+commit
git push

将本地提交推送到远程仓库，同步给团队成员

$ git push origin main
$ git push -u origin main # 首次
git pull

从远程拉取最新代码并合并到当前分支

$ git pull origin main
$ git pull --rebase # 避免merge
git diff

查看工作区与暂存区、或暂存区与仓库的差异

$ git diff
$ git diff --staged
$ git diff HEAD~1
git restore

撤销修改：用仓库版本覆盖工作区或暂存区

$ git restore file.ts
$ git restore --staged file.ts
$ git restore . # 撤销全部
