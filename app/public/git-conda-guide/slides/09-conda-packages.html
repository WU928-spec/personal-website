Chapter 02 · Conda

包管理

安装、卸载、更新、搜索 —— 管理 Python 包的核心操作

conda install

从 conda 仓库安装包，自动解决依赖

$ conda install numpy
$ conda install numpy=1.24
$ conda install numpy pandas matplotlib
优先使用 conda 仓库，兼容性更好
pip install

当 conda 找不到包时，用 pip 补充安装

$ pip install requests
$ pip install -r requirements.txt
$ pip install package==1.2.3
conda 优先，pip 补充，不要混用
conda remove

卸载已安装的包

$ conda remove numpy
$ conda remove numpy pandas
$ conda uninstall numpy # 同 remove
conda update

更新包到最新版本

$ conda update numpy
$ conda update --all # 更新全部
$ conda update conda # 更新 conda 本身
conda list

列出当前环境的所有包

$ conda list
$ conda list numpy # 搜索特定包
$ conda list | grep pandas
conda search

搜索可用的包版本

$ conda search numpy
$ conda search numpy=1.24
$ conda search --channel conda-forge pkg
