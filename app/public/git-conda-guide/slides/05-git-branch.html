分支管理

并行开发、功能隔离、安全合并

分支结构示意
git branch 查看/创建

列出所有分支，或创建新分支

$ git branch # 列出分支
$ git branch feature/login # 创建
$ git branch -d feature/login # 删除
git checkout 切换

切换到指定分支或提交

$ git checkout develop
$ git checkout -b feature/new # 创建并切换
$ git checkout -- file.ts # 撤销修改
git merge 合并

将指定分支合并到当前分支

$ git checkout main
$ git merge develop
$ git merge --no-ff feature/x # 保留分支历史
git rebase 变基

将当前分支的提交移到目标分支顶端，保持线性历史

$ git checkout feature/x
$ git rebase main
$ git rebase -i HEAD~3 # 交互式整理
