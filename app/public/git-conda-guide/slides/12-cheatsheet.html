快速参考卡

最常用的命令一览，建议截图保存

G
Git 速查
git init初始化仓库
git clone <url>克隆远程仓库
git status查看状态
git add .暂存所有修改
git commit -m "msg"提交更改
git push origin main推送到远程
git pull origin main拉取并合并
git branch -a列出所有分支
git checkout -b feat/x创建并切换分支
git merge develop合并分支
git stash / pop临时保存/恢复
git log --oneline简洁提交历史
C
Conda 速查
conda create -n env创建环境
conda activate env激活环境
conda deactivate退出环境
conda env list列出环境
conda install pkg安装包
conda remove pkg卸载包
conda list查看已安装包
conda update --all更新全部包
conda env export > f.yml导出环境
conda env create -f f.yml从文件创建
conda env remove -n env删除环境
conda clean --all清理缓存
