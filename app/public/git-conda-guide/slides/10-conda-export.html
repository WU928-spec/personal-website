Chapter 02 · Conda

环境导出与复现

让团队协作无缝衔接：导出环境 → 分享 → 一键复现

conda env export

导出当前环境为 YAML 文件，包含所有包和版本

$ conda env export > environment.yml
$ conda env export --no-builds > env.yml # 去掉 build 号
$ conda env export --from-history > env.yml # 只含手动安装的
--from-history 最实用，只记录你主动安装的包，体积最小
conda env create -f

从 YAML 文件创建环境，完美复现

$ conda env create -f environment.yml
$ conda env create -f env.yml -n newenv # 指定新名
$ conda env update -f environment.yml # 更新现有
environment.yml 示例
name: blog-api
channels:
- conda-forge
- defaults
dependencies:
- python=3.11
- fastapi=0.104
- uvicorn=0.24
- sqlalchemy=2.0
- pydantic=2.5
- pytest=7.4
- pip
- pip:
- httpx==0.25.0
# 提交到 Git，队友只需 conda env create -f
