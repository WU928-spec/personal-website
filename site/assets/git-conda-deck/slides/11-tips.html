Git 和 Conda 的进阶用法与踩坑指南

◆
Git 进阶技巧
撤销错误提交
soft 保留修改，hard 彻底丢弃
git reset --soft HEAD~1
修改最后一次提交
补充遗漏的文件或修改提交信息
git commit --amend -m "新信息"
查看某行代码谁写的
快速定位代码责任人
git blame filename.ts -L 10,20
忽略文件不提交
.gitignore 模板：node_modules/ .env __pycache__/
git checkout -- .gitignore
◇
Conda 踩坑指南
conda 和 pip 混用
先用 conda 安装，conda 找不到再用 pip，避免依赖冲突
conda install numpy && pip install pkg
环境激活不生效
初始化 shell：conda init bash/zsh，然后重启终端
conda init bash && exec bash
解决环境冲突
创建干净环境测试，逐步添加包定位冲突源
conda create -n test python=3.11
清理缓存释放空间
定期清理未使用的包和缓存
conda clean --all
