Chapter 01 · Git

团队协作

多人协作时的常用命令与最佳实践

git remote

管理远程仓库地址

$ git remote -v # 查看远程
$ git remote add origin https://...
$ git remote set-url origin git@github.com:... # 改 SSH
git fetch

下载远程分支最新状态，但不合并到本地

$ git fetch origin
$ git fetch --all
$ git fetch origin main # 指定分支
fetch 是安全的"查看"操作，不会修改你的工作区
git stash

临时保存未提交的修改，方便切换分支

$ git stash # 暂存
$ git stash pop # 恢复
$ git stash list # 查看列表
$ git stash drop # 删除
git cherry-pick

将指定提交应用到当前分支

$ git cherry-pick a1b2c3d
$ git cherry-pick -n a1b2c3d # 不自动提交
