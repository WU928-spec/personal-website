实战场景

实习生日常开发中的典型工作流

1
新入职：克隆项目 + 配置环境
第一天到团队，拿到项目地址，快速搭建开发环境
git clone git@github.com:team/project.git # 克隆代码
cd project && conda env create -f environment.yml # 创建环境
conda activate project-env # 激活环境
git checkout -b feature/my-first-task # 创建功能分支
2
日常开发：修改代码 → 提交 → 推送
完成一个功能点后的标准提交流程
git add . # 暂存修改
git commit -m "feat: add user login" # 提交
git pull origin main # 先拉取最新（避免冲突）
git push origin feature/my-task # 推送到远程
3
紧急修复：临时切换分支修 Bug
正在开发功能时，需要紧急修复线上问题
git stash # 保存当前进度
git checkout main && git pull # 切换到主分支
git checkout -b hotfix/critical-bug # 创建修复分支
# 修复代码 → commit → push → PR → merge
git checkout feature/my-task && git stash pop # 恢复之前进度
