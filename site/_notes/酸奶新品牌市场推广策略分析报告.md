# 综合案例 1：酸奶新品牌市场推广策略分析

> **数据来源**：`case1.dta`（1,751 条观测，3 个变量：brand / city / score）  
> **分析工具**：Stata  
> **执行日期**：2026-05-24

---

## 一、研究目的

1. 分析在 10 种受试酸奶中哪种最受欢迎。
2. 新口味 1 和新口味 2 的主要竞争对手是哪些品牌，与它们之间的差距明显吗？
3. 消费者的口味在 4 个城市之间存在显著地区差异吗？

---

## 二、Stata 执行代码

```stata
clear all
set more off
set scheme s1color

use "case1.dta", clear

*----- Step 0. 数据确认 -----
tab brand
tab city
describe

*----- 问题1：10种酸奶中哪种最受欢迎？ -----
tabstat score, by(brand) statistics(mean sd min max n) format(%9.3f)

preserve
collapse (mean) mean_score=score (sd) sd_score=score (count) n=score, by(brand)
gsort -mean_score
gen rank = _n
list rank brand mean_score sd_score n, sep(0)
restore

graph bar (mean) score, over(brand, sort(1) descending) ///
    bar(1, color(navy)) ///
    ytitle("平均口味评分（满分9分）") ///
    title("10种酸奶品牌口味满意度排名") ///
    blabel(bar, format(%9.2f) size(small)) ///
    yline(5, lpattern(dash) lcolor(cranberry)) ///
    note("红色虚线为理论中位线（5分）", size(small))
graph export "fig1_brand_ranking.png", replace width(1200)

*----- 问题2：新口味1、新口味2的竞争对手是谁？差距明显吗？ -----
encode brand, gen(brand_num)

anova score brand_num

pwmean score, over(brand_num) mcompare(bonferroni) effects

*----- 问题3：4个城市消费者口味是否存在显著差异？ -----
tabstat score, by(city) statistics(mean sd min max n) format(%9.3f)

oneway score city, tabulate bonferroni

pwmean score, over(city) mcompare(tukey) effects

graph bar (mean) score, over(city, sort(1) descending) ///
    bar(1, color(forest_green)) ///
    ytitle("平均口味评分") ///
    title("四大城市酸奶口味满意度对比") ///
    blabel(bar, format(%9.2f))
graph export "fig2_city_comparison.png", replace width(1200)

graph box score, over(city) ///
    ytitle("口味评分") title("各城市口味评分分布箱线图")
graph export "fig3_city_boxplot.png", replace width(1200)
```

## 四、综合结论

1. **最受欢迎的品牌**：传统品牌 **K**（6.747 分）和 **G**（6.692 分）位居前两名，新口味 **N**（6.494 分）和 **M**（6.385 分）分列第 3、5 位，整体处于上游梯队。

2. **新口味的竞争力**：两种新口味与最强传统品牌（K、G、L）之间**无显著差距**，且对部分传统品牌（F、H、J）具有**统计显著的优势**，具备上市竞争的实力。

3. **地区差异**：四大城市间口味偏好存在**轻微差异**，主要表现为城市 4 与城市 3 之间的显著差异，其余城市间差异不明显。企业在制定区域推广策略时可适当关注城市 3 的偏低评分，但无需进行大规模口味差异化调整。
