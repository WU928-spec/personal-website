# 长期主义生活博客视觉改造设计

日期：2026-11-02

## 1. 目标

在保留现有功能、数据与路由的前提下，将个人网站重新设计为真诚、耐读、适合长期写作的中文独立生活博客。

新网站应让访客首先看到真实文字与生活内容，而不是技能标签、工具图标或大面积个人宣传。视觉参考是独立博客的内容密度与长期档案感，不是机械复制某个主题。

## 2. 参考网站与提炼结果

实际查看的参考：

- 左素生 `https://z.arlmy.me/`：个人兴趣、最近所想、分类与长期文章档案，体现个人所有权和内容积累。
- 土木坛子 `https://tumutanzi.com/`：文章标题、日期、摘要与适量留白，内容立即成为主角。
- Cup of Jo `https://cupofjo.com/`：清晰文章流、照片节奏、亲切标题和低学习成本导航。

设计取舍：保留内容优先与亲切感，不复制其导航分类、广告、评论数量、订阅模块或站点结构。

## 3. 不变范围

- 保留首页、记忆碎片、文章笔记、小工具、管理登录和隐藏星空路由。
- 保留 Supabase 数据、localStorage、现有读写与同步语义，不删除或迁移数据。
- 保留 Markdown、GFM、LaTeX、代码高亮、编辑器、搜索、中英文、深浅主题和减少动态效果支持。
- 保留 `/notes` 与旧 `/obsidian` 重定向、五个小工具路由和页脚隐藏星空入口。
- 不新增后端、CMS、UI 框架或数据源。
- 用户已授权创建少量随机生活随笔作为展示内容；应通过现有笔记编辑器保存为真实可编辑数据。若云端不可用，不伪造写入成功，保留空态验收。

## 4. 视觉语言

### 色彩

浅色以暖纸白和墨黑为主，酒红作为唯一主要强调色。边框采用低对比暖灰，避免上一版棕橙与鼠尾草绿继续主导页面。

深色使用柔和深灰而非纯黑，酒红提亮到足够对比度。正文、辅助文字和链接在两种主题下均清晰可读。

### 字体与排版

中文标题使用有书卷气的衬线字体，正文使用清晰的中文黑体；英文展示标题沿用衬线字体。标题尺寸使用 `clamp()`，避免极端视口下过大或过小。

文章正文行宽控制在约 680px，正文保持现有 17px 左右的舒适字号和较高行距。日期、分类等元信息使用较小但不低于可读性的字号。

### 装饰与动效

不使用打字动画、无限循环背景、随机图形或大面积光效。装饰仅限细分隔线、编号和少量照片画幅变化。

保留短促淡入与链接状态变化；减少动态效果用户不得经历延迟入场或位移动画。

## 5. 页面结构

### 导航

左侧使用文字品牌 `Jasper` 与一句简短个人小注，右侧仅首页、动态、笔记及必要的搜索、语言、主题控制。

移动菜单继续提供小工具次级入口。登录、个人资料和彩蛋目录不出现在公开导航。

### 首页

1. **欢迎与最新内容**：使用“记录生活，也记录那些慢慢想清楚的事。”作为核心标题；下方直接呈现最新笔记的标题、日期、摘要和阅读入口。无数据时显示普通欢迎语和笔记入口，不显示骨架或错误阻塞页面。
2. **近期动态**：以不同画幅的照片和短文形成连续内容流，首条可稍大，其余保持紧凑；无照片时以文字为主。
3. **更多文字**：以日期、标题和摘要构成文章列表，使用细分隔线而非重复卡片。
4. **关于我**：头像缩小为个人档案的一部分，配合真实简介与兴趣字段；不再占首屏一半。
5. **公开项目**：保留真实 GitHub 仓库，以简单条目呈现，不显示虚构统计或贡献图。

首页整体应像持续更新的个人文章流，而不是互不相干的功能仪表盘。

### 笔记列表与阅读页

列表强调标题、日期、摘要与分类。阅读页使用居中的纸张式正文，标题、元信息、目录、正文和标签层级清晰。

保留现有标准 Markdown/GFM/LaTeX 行为。代码、表格、独立公式与长行内公式仅在自身容器滚动，不造成页面横向溢出。

### 页脚

使用简洁联系链接、版权与小工具入口。隐藏星空入口仍放在签名末尾，保持星芒装饰、键盘焦点与 aria-label。

## 6. 组件与数据

- `Navbar.tsx`：文字品牌、收缩导航和移动菜单视觉更新。
- `HeroSection.tsx`：欢迎语与最新笔记入口，复用 `fetchNotes()` 和 `selectLatestNotes()`，独立处理加载与空态。
- `RecentMomentsSection.tsx`：连续照片/文字内容流。
- `LatestNotesSection.tsx`：编辑式文章列表。
- `IntroSection.tsx`：轻量个人档案，不重复主视觉头像。
- `GitHubSection.tsx`、`RepoCard.tsx`：真实仓库条目。
- `NotesIndex.tsx`、`NoteArticle.tsx`、`render-components.tsx`：统一文章排版。
- `Footer.tsx`、`StarryLink.tsx`：简洁收尾和隐藏入口。
- `index.css`、`tailwind.config.js`：集中维护颜色、字体和可读性变量。

现有数据函数与接口保持兼容，不为视觉改造重写业务逻辑。

## 7. 空态与错误

最新笔记、动态和 GitHub 请求失败时，各分区独立显示简短空态。欢迎语、个人介绍、导航和页脚不依赖远程数据，始终可用。

空态不展示虚构文章、照片、个人信息或项目。加载状态不使用无限动画。

## 8. 测试与验收

保留并更新现有测试，新增或调整测试仅针对实际行为：最新笔记选择、空态、中英文文案、链接地址、键盘焦点与减少动态效果。

必须运行：

```bash
cd app
npm test -- --run
npm run build
npm run lint
```

浏览器验收：

- 首页在 375px、768px、1440px 下无横向溢出，最新内容和个人介绍清晰可见。
- 深色、浅色和英文模式无不可读文字或残留旧文案。
- 动态、笔记、五个小工具、管理路由、旧笔记重定向和隐藏星空均可用。
- Markdown/GFM/LaTeX、代码复制、目录锚点和编辑器焦点行为不回归。
- 远程请求失败时首页其他内容仍正常。
- 无打字等待、无限循环动画或背景标签页导致的误导性验收。
