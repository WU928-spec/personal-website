Chapter 02 · Conda

基础操作

创建、激活、查看环境 —— 环境管理的第一步

conda create

创建新的虚拟环境，指定 Python 版本

$ conda create -n myenv python=3.11
$ conda create -n myenv python=3.9 numpy pandas
$ conda create -n myenv --clone base # 克隆
环境名建议用项目名，如 blog-api、data-pipeline
conda activate

激活指定环境，之后所有操作都在该环境中

$ conda activate myenv
$ conda deactivate # 退出当前环境
$ conda activate base # 回到 base
conda env list

列出所有环境，带 * 的为当前激活环境

$ conda env list
# conda environments:
base * /Users/xxx/miniconda3
myenv /Users/xxx/miniconda3/envs/myenv
blog-api /Users/xxx/miniconda3/envs/blog-api
conda remove

删除指定环境及其所有包

$ conda remove -n myenv --all
$ conda env remove -n myenv # 同上
删除前确认没有重要代码或数据留在环境中！
